# StudyMate

AI-powered learning platform and digital bookstore (React + TypeScript + Vite + Tailwind + Gemini).

## Deploy (GitHub → Vercel)

1. Push this repo to GitHub (all files at root).
2. Import the repo on Vercel.
3. Add Environment Variable:
   - Name: `GEMINI_API_KEY`
   - Value: your key from https://aistudio.google.com/apikey
4. Deploy.

Framework: Vite. Build command: `npm run build`. Output: `dist`.
